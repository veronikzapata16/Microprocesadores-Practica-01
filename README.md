# Práctica 01: Análisis de un código ensamblador.

```asm
load #10, A
```
Carga el número 10 en el registro A.
```asm
load #11, B
```
Carga el número 11 en el registro B.
```asm
add A, B, C
```
Suma A + B y el resultado lo guarda en el registro C.
```asm
store C, #255
```
Guarda lo que está en C en la memoria #255.
```asm
jmp C
```
Hace un salto a la dirección C.
